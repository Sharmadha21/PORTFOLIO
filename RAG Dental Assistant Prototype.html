02 / Product decisions

Built to be inspectable

The prototype prioritizes safe, traceable behavior over conversational breadth—the right tradeoff for a healthcare education workflow.

DECISION 01

RAG over fine-tuning

Clinic policies and care guides change. Retrieval lets the team update source content without retraining, display citations, and constrain responses to approved material.

DECISION 02

Evaluation plan

A golden Q&A set would test whether the correct document is retrieved and whether unsupported questions are refused.

  • Top-1 retrieval accuracy
  • Abstention precision and recall
  • Unsafe-query redirect rate
NEXT RELEASE

Production path

A production version would add authenticated EHR integration, role-based access, multilingual content, voice input, clinical review workflows, and monitored source versioning.
